LIBRATRACK LIBRARY ISSUE REGISTER - SUBMISSION FILES

1. library_srs.docx - one-page SRS with six testable requirements (REQ-01 to REQ-06).
2. library_test_conditions.xlsx - 14 test conditions, at least two per requirement.
3. library_classes.png - class diagram for Book, Member, Loan and StudentMember inheritance.
4. library_queries.sql - CREATE TABLE, 12 INSERT rows and 10 SELECT queries.
5. library_query_output.docx - expected SQL result tables for the 10 queries.

Important: The output document contains expected result tables, not screenshots from your class's online SQL editor. If screenshots are mandatory, run library_queries.sql in that editor and insert the screenshots into the output document.
